# Web Search Skill

When the user asks you to search the web, find information online, or look something up:

1. Use the `websearch` tool with a clear, specific query
2. Review the results and pick the most relevant ones
3. Use `webfetch` to get full page content if snippets aren't enough
4. Summarize findings concisely, citing sources

## Guidelines

- Prefer specific queries over broad ones
- Cross-reference multiple sources for factual claims
- Always include source URLs so the user can verify
- If the first search doesn't find what you need, try rephrasing
- For technical questions, prefer official documentation over blog posts
